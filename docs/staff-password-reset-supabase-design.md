# تصميم إعادة تعيين كلمة مرور الحساب الفرعي عبر Supabase Auth

## الحالة الانتقالية

مسار `staff.resetPassword` متوقف صراحةً. لا يستدعي MySQL ولا يعدّل مستخدماً في Supabase Auth، لأن التعديل الإداري لكلمة المرور هو عملية خارج حدود معاملة PostgreSQL ولا يمكن التراجع عنه بإعادة كلمة المرور السابقة. لا يجوز إعادة تفعيله كاستدعاء منفرد لـ`auth.admin.updateUserById` يتبعه تحديث قاعدة البيانات.

## النموذج المطلوب قبل التفعيل

| المرحلة | الضمان المطلوب |
| --- | --- |
| التهيئة الذرية | دالة PostgreSQL تتحقق من المالك وصلاحية `manageTeam` ونطاق المستأجر/الفرع وملف الموظف و`users.auth_user_id`، ثم تنشئ سجل نية إعادة تعيين غير قابل للتكرار وسجل تدقيق مبدئي تحت قفل المستأجر. |
| تحديث Supabase Auth | خدمة خادمية تستعمل service role لتحديث حساب Auth المحدد بالـUUID الموثق فقط، ولا تسجل كلمة المرور المؤقتة أو تعرضها في سجل التدقيق. |
| الإتمام الذري | دالة PostgreSQL ثانية تربط نتيجة Auth بسجل النية، تضبط `must_change_password` و`temporary_password_issued_at` وتحوّل حالة النية إلى مكتملة مع تدقيق نهائي. |
| الفشل والتعويض | عند فشل Auth، تُغلق النية كفاشلة بلا تغيير بيانات المستخدم. وعند فشل الإتمام بعد نجاح Auth، يبقى سجل النية قيد الإتمام للمراجعة ولا يعاد إنشاء كلمة مرور مختلفة تلقائياً. |

## متطلبات التفعيل

يتطلب التفعيل اعتماد مالك المنصة لعمر النية، ومسار معالجة حالات الإتمام العالقة، وسياسة عرض كلمة المرور المؤقتة لمرة واحدة فقط، واختبارات معزولة لفشل Auth وللنطاق العابر للمستأجر. لا يتطلب التصميم إرسال بريد أو رسالة خارجية، ولا يُفعل أي إرسال ضمن هذه الدورة.

## إنشاء الحسابات الفرعية

إنشاء الحساب الفرعي متوقف انتقالياً أيضاً. المسار الموروث كان ينشئ مستخدم Supabase Auth ثم يحدّث MySQL، لذلك لا يجوز استعماله بعد اعتماد Supabase كمصدر إنتاجي وحيد.

تتطلب إعادة التفعيل دورة تعويضية مشابهة: تتحقق دالة PostgreSQL من المالك وسياسة الدور والحد تحت قفل المستأجر، وتنشئ نية مختصرة؛ ثم تنشئ الخدمة الخادمية مستخدم Auth؛ ثم تستدعي RPC ذرية لإنشاء `users` و`tenant_members` و`staff_profiles` وسجل التدقيق. عند فشل الإتمام، تحذف الخدمة مستخدم Auth الذي أنشأته فقط وتغلق النية كفاشلة. يجب أن تكون المحاولة متكررة بمفتاح idempotency ولا تعرض كلمة المرور المؤقتة في التدقيق أو السجلات.
