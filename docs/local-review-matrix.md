# PowerHub — مصفوفة تتبع المراجعة المحلية

## الغرض والنطاق

تستند هذه المصفوفة إلى مصدر الصلاحيات الوحيد `shared/powerhub-rbac.ts`، وتربط كل واجهة أو إجراء حساس بنتيجة الإتاحة المتوقعة ودليل تحقق محلي. يرمز **إنشاء/تعديل** إلى قدرة كتابة محكومة بالدور والمحطة، و**قراءة** إلى عرض بيانات المحطة المعينة فقط، و**محظور** إلى غياب الإجراء من الواجهة ورفض الإجراء في الخادم عند استدعائه مباشرةً.

> لا تشمل هذه المراجعة تشغيل مزود WhatsApp أو SMS، أو نشر الموقع، أو مهمة Heartbeat؛ فجميعها مؤجل بطلب المستخدم.

## مصفوفة الصفحات والمسارات الحساسة

| الواجهة أو المسار | قرار الوصول المحلي | دليل التحقق الحالي |
|---|---|---|
| لوحة الملخص `/` | كل دور نشط يرى ملخص المحطة المعينة فقط، مع اختيار المحطة من قائمة الوصول | `supplemental-pages.ui.test.tsx` و`tenant-isolation.integration.test.ts` |
| المشتركين `/subscribers` | المالك والمدير والمحاسب يكتبون؛ بقية الأدوار قراءة فقط | `role-guards.ui.test.tsx` + اختبار العزل |
| المولدات `/generators` | المالك والمدير والفني يكتبون؛ بقية الأدوار قراءة فقط | `role-guards.ui.test.tsx` (فني ينشئ ومحاسب قراءة فقط) + اختبار العزل لحدود الفني |
| العدادات والقراءات `/readings` | المالك والمدير والمحاسب والفني يسجلون؛ المحصل والمشاهد بلا إنشاء | `role-guards.ui.test.tsx` + اختبار العزل لحدود الفني والمحصل |
| الفوترة `/invoices` | المالك والمدير والمحاسب يصدرون ويشاركون؛ بقية الأدوار قراءة فقط | `role-guards.ui.test.tsx` (إصدار ومشاركة) + اختبار التكامل |
| الرابط العام `/invoice/:token` | لا يتطلب دخولاً؛ يتطلب رمز رابط صالح وغير ملغى وغير منتهٍ | `supplemental-pages.ui.test.tsx` + إجراء `publicByToken` |
| التحصيل `/collections` | المالك والمدير والمحاسب والمحصل يسجلون؛ المحصل يفتح ويغلق جلسته فقط | `role-guards.ui.test.tsx` + اختبار العزل لجلسة المحصل |
| المصروفات `/expenses` | المالك والمدير والمحاسب يكتبون؛ بقية الأدوار قراءة فقط | `role-guards.ui.test.tsx` (محاسب ينشئ ومحصل قراءة فقط) + إجراءات الخادم المحكومة |
| التقارير `/reports` | تعرض بيانات المحطة المتاحة للمستخدم؛ اختيار المحطة لا يتجاوز التعيين | `supplemental-pages.ui.test.tsx` + `sites.list` في اختبار العزل |
| الفريق `/settings` | المالك فقط يدير الأدوار؛ لا تمنح ملكية محطة ملكية المستأجر | `role-guards.ui.test.tsx` + اختبار العزل |
| إعدادات المراسلة `/messaging` | المالك فقط يهيئ WhatsApp وSMS؛ يعرض الطابور وفق المحطة والصلاحية | `role-guards.ui.test.tsx` + اختبار القنوات + اختبار العزل |
| التدقيق `/audit` | المالك والمدير والمحاسب والمشاهد يقرؤون؛ المحصل والفني محظوران | `role-guards.ui.test.tsx` + RBAC |

## تدفقات محكومة اختُبرت صراحةً

| عزل المستأجر والمحطة | `tenant-isolation.integration.test.ts` | 4 اختبارات تكاملية تثبت رفض المعرّفات عبر المستأجر/المحطة وتقييد قائمة المحطات |
| مزامنة القراءة دون تكرار | `tenant-isolation.integration.test.ts` و`offline-reading-queue.test.ts` | يعاد الطلب نفسه بالمعرف الميداني من دون إنشاء قراءة ثانية |
| جلسة المحصل والإغلاق النقدي | `tenant-isolation.integration.test.ts` و`role-guards.ui.test.tsx` | يتطلب تسجيل دفعة المحصل جلسة مفتوحة، وتظهر واجهة الفتح للمحصل |
| إنشاء ومشاركة الفاتورة | `tenant-isolation.integration.test.ts` و`role-guards.ui.test.tsx` | تنشأ البنود ضمن المستأجر الصحيح، ويستدعى إنشاء الرابط من الفاتورة الصادرة |
| طابور WhatsApp وSMS | `notification-channels.test.ts` و`tenant-isolation.integration.test.ts` | ينشأ سجل مستقل لكل قناة نشطة، مع بديل WhatsApp محلي عند غياب التهيئة |
| سجل الإشعارات والتدقيق | `role-guards.ui.test.tsx` و`tenant-isolation.integration.test.ts` | يرفض إعادة المحاولة عبر مستأجر آخر؛ ويتغير ظهور التدقيق وفق الدور |

## أوامر الاعتماد المحلي

```bash
pnpm check
pnpm test
RUN_TENANT_ISOLATION_TESTS=1 pnpm vitest run server/tenant-isolation.integration.test.ts
pnpm build
```

نجاح الأوامر أعلاه، إلى جانب المعاينة البصرية للوحة التحكم بعد إعادة التشغيل، هو معيار اعتماد النسخة المحلية فقط. ويبقى اختبار التسليم الحقيقي من مزود خارجي خطوة منفصلة لا تبدأ إلا بطلب مستخدم صريح.
