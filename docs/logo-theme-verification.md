# تحقق شعار الثيمين

- تم إنشاء نسخة الثيم الغامق مع تحويل النص الداكن إلى أبيض.
- اختبارات `PowerHubLogo` تثبت اختيار الأصل الفاتح والغامق حسب الثيم.
- فحص TypeScript والبناء ناجحان.
- أظهر الفحص البصري الأول تعذر تحميل الصور قبل تفعيل `storage-proxy`.
- بعد تفعيل `storage-proxy` وإعادة تشغيل الخادم، ظهر الشعار فعلياً في الصفحة الرئيسية وصفحة تسجيل الدخول.
- عند تفعيل الثيم الغامق فعلياً، تغيّر الأصل إلى `powerhub-logo-dark` وظهر النص الأبيض مع بقاء العناصر الذهبية والتكوين العام واضحاً.
- فحص نطاق `powerhup-com-ps.vercel.app` أعاد `DEPLOYMENT_NOT_FOUND`، بينما نطاق `powerhub-platform.vercel.app` يعرض مسارات `/manus-storage/...`؛ يلزم فحص استجابة الأصل مباشرة وتحديد نطاق الإنتاج الصحيح.
- سبب الخلل: `vercel.json` كان يمرر `/manus-storage/*` إلى `index.html`، لذلك كانت الصور تعود 404. الإصلاح يضيف إعادة كتابة إلى دالة API ومسار Express مطابقاً لها.
- تحقق محلياً من مسار الشعار: استجابة `307` إلى رابط التخزين الموقّع، مع نجاح TypeScript والاختبارات والبناء.
