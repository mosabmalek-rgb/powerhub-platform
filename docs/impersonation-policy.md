# سياسة انتحال جلسة مالك المولد

## الحالة الحالية

ميزة **انتحال الجلسة غير مفعّلة** في PowerHub. لا يوجد إجراء خادمي لإنشاء جلسة باسم مالك مولد، ولا تعرض واجهة الإدارة أي زر يفتح مساحة مستأجر بصفته. يعيد مسار الإدارة الداخلي `impersonationStatus` حالة `enabled: false` صراحةً، ليكون هذا القرار قابلاً للتحقق بالاختبارات وليس مجرد نص واجهة.

## شرط أي تفعيل مستقبلي

لا يمكن تفعيل الميزة إلا بعد اعتماد سياسة مستقلة تغطي سبب الوصول، وموافقة واضحة لكل جلسة، ومدة قصيرة لا يمكن تمديدها بصمت، وهوية الآدمن المنفذ، وهوية المالك المستهدف، وعنوان الشبكة، ووقت البدء والانتهاء، وسجل تدقيق غير قابل للتعديل. يجب أن يظهر شريط تحذيري دائماً داخل أي جلسة مراقبة مستقبلية، ولا يجوز أن تسمح هذه الجلسة بتغيير بيانات الدخول أو وسائل الدفع أو إعدادات الأمان.

## البديل المتاح الآن

يستخدم آدمن PowerHub **طلب استرداد وصول موثقاً** عبر OAuth أو مراجعة يدوية؛ يسجل الطلب محلياً في `accessRecoveryRequests` وسجل التدقيق، ولا يرسل رسالة خارجية ما دامت قنوات التفعيل مؤجلة.
