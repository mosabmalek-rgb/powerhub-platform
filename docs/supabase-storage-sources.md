# مراجع Supabase Storage

اعتمدت ترحيلات التخزين في PowerHub على المراجع الرسمية التالية:

- [Storage Buckets](https://supabase.com/docs/guides/storage/buckets/fundamentals): يوضح الفرق بين الحاويات الخاصة والعامة، وأن الحاويات الخاصة هي الافتراضية وتحتاج إلى رابط موقّع أو جلسة مصادق عليها للتحميل.
- [Storage Access Control](https://supabase.com/docs/guides/storage/security/access-control): يوضح أن عمليات التخزين تخضع لسياسات RLS وأن مفتاح الخدمة لا يُشارك مع العميل ويقتصر على الخادم الموثوق.
- [Secure configuration of Supabase products](https://supabase.com/docs/guides/security/product-security): قائمة مراجعة أمنية لمنتجات Supabase، بما فيها Auth وRLS وStorage.
