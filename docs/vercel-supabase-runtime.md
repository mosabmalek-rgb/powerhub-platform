# تشغيل PowerHub على Vercel وSupabase

## النطاق المرحّل

يعمل مسار الويب وواجهات tRPC والـMobile API المرحّلة عبر **Supabase Auth** و**Supabase Postgres/Storage**. كما أن نقطة Vercel تستورد الحزمة الخادمية المبنية من `dist/index.js` وتعيد توجيه `/api/*` إلى معالج Express.

## متغيرات الإنتاج للمسارات المرحّلة

| المتغير | الغرض |
| --- | --- |
| `SUPABASE_URL` أو `VITE_SUPABASE_URL` | عنوان مشروع Supabase لمصادقة الخادم والعميل. |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | مفتاح Supabase العام للعميل والتحقق من الجلسات. |
| `SUPABASE_SERVICE_ROLE_KEY` | مفتاح خدمة خادمي فقط لاستدعاءات Supabase المحمية؛ لا يُعرض للعميل. |
| `JWT_SECRET` | مفتاح الجلسات أو التوقيعات الخادمية المتبقية التي تحتاجه. |

لا تتطلب المسارات المرحّلة متغيرات Forge أو OAuth أو قاعدة MySQL. أي مسار خارجي لم يُصمم بعد على Supabase/Vercel، بما في ذلك الإشعارات الداخلية ومزودات الرسائل، يعيد خطأً انتقالياً منظماً ولا ينبغي تزويده باعتمادات تشغيلية.
