Staging project: `iyuryuhaylhisjfcrwkz`.

- Generator browser sync RPCs are `SECURITY INVOKER` and derive the application user from `auth.uid()`.
- Browser sync RPCs have `EXECUTE` for `authenticated`.
- Legacy internal-identity Generator RPCs do **not** have `EXECUTE` for `authenticated`.
- Generator idempotency is backed by the unique `client_operation_id` index.
- `offline_sync_operations` accepts `generator_create` and `generator_update` while retaining existing subscriber/invoice/payment operation types.
- Generator and offline-sync tables have tenant-scoped RLS policies.
