## P7.3 release gate

P7.3 may expand offline operational CRUD only while preserving the P7.2 safety model:

1. Reuse the existing offline queue and unified sync executor.
2. Keep local records scoped by authenticated user and site.
3. Preserve `clientOperationId` across retries/replays.
4. Enforce dependency ordering for related operations.
5. Keep financial, authorization-sensitive, audit, messaging, and administrative mutations server-authoritative unless separately approved.
6. Verify every new mutation kind with deterministic tests and isolated staging replay.
7. Do not use production data for testing.
8. Require CI, Security, Preview, tenant/site isolation, and release-gate verification before production promotion.

Production remains on the established P6 release until an explicit P7 production promotion decision.
