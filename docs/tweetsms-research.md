# ملاحظات تحقق TweetSMS

تمت مراجعة الموقع الرسمي لخدمة TweetSMS في 23 أغسطس 2026. تؤكد الصفحات الرسمية توفر **بوابات API للمبرمجين**، و**نظام حسابات فرعية**، وتقارير تسليم وإرسال SMS للمؤسسات، بما يتوافق مع النموذج الإداري المعتمد في PowerHub.

لم تنشر الصفحات العامة مسارات API أو شكل المصادقة أو حقول طلب الإرسال/الرصيد. لذلك يجب عدم تخمين نقاط النهاية؛ يبقى الإرسال الفعلي واختبار الاتصال معلقين على وثائق API الرسمية أو بياناتها من TweetSMS.

## المصادر

1. [الموقع الرسمي لـ TweetSMS](https://tweetsms.ps/) — يذكر الإرسال عبر API للمؤسسات وإدارة الحسابات الفرعية.
2. [خدمات موقع TweetSMS](https://www.tweetsms.ps/index.php/pages/show/1) — يذكر بوابات API للمبرمجين وخدمات الموزعين والحسابات الفرعية.
3. [من نحن — TweetSMS](https://www.tweetsms.ps/index.php/pages/show/4) — يذكر واجهات API وخدمات الموزعين وتشكيل الحسابات الفرعية.
