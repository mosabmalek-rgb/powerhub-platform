# B5 — قياس HTTP المالي المصادق

هذه أداة قياس قراءة فقط لثلاثة تقارير مالية عبر شبكة HTTPS، وتستخدم جلسة واحدة مصادقة على Staging. لا تنشئ أي عمليات مالية.

الاختبارات السبعة داخل CI تفحص الأداة بمحاكاة الاستجابات؛ نجاح CI لا يعني نجاح اختبار HTTP الحقيقي.

## المتغيرات المطلوبة (تحقن بأمان خارج السجلات)

- POWERHUB_B5_PREVIEW_URL: عنوان Preview المطابق لـ commit الذي جرى قبوله.
- POWERHUB_B5_ACCESS_TOKEN: رمز دخول مؤقت لحساب اختبار موجود ومصرح له بقراءة التقارير؛ لا تشاركه في المحادثة.
- POWERHUB_B5_DEVICE_ID: UUID لجهاز مصادق بالفعل بنفس الحساب؛ لا تتجاوز فحص الجهاز.
- POWERHUB_B5_TENANT_ID: رقم الاشتراك التجريبي المتوقع في كل استجابة (الافتراضي 1).
- POWERHUB_B5_SITE_ID: رقم الفرع التجريبي (الافتراضي 1).
- POWERHUB_B5_PERIOD: الفترة (الافتراضي 2026-11).
- POWERHUB_B5_P95_BUDGET_MS: حد p95 المعتمد، بالألف من الثانية، وهو مطلوب صراحة.
- POWERHUB_B5_SAMPLES: من 100 إلى 400 قراءة لكل تقرير (افتراضي 100).
- POWERHUB_B5_CONCURRENCY: من 1 إلى 4 (افتراضي 4).

## التنفيذ

node scripts/b5-financial-http-benchmark.mjs

الاختبار يتحقق من `checks` في `/api/ready`، ويضع مهلة 8000ms لكل طلب مالي. يرفض أي 401 أو 403 أو 429 أو 500 أو اختلاف في الاشتراك أو الفرع أو الفترة أو الاعتماد المحاسبي. يسجل عدد العينات الصحيحة والمحاولات وأخطاء 500/502/503/504 والمهلة منفصلة، ويتوقف بعد أول دفعة عينات فاشلة. لا يحتوي الناتج على رموز الدخول أو نصوص البيانات المالية. يجب مقارنة p95 بالحد المعتمد وتوثيق p50 وp99 وحالة SHA وسلامة Staging.

**الحالة عند إنشاء هذه الأداة:** لم يُنفذ اختبار HTTP المصادق الحقيقي؛ لا توجد جلسة اختبار واحدة صالحة ومتاحة لأداة القياس. استثناء اختبار حسابين مستقلين لا يعني استثناء هذا الشرط ولا يسمح بإنشاء نجاح صوري.
