# مراجعة PowerHub المحلية: العزل والصلاحيات

## سياسة النطاق

تعامل المنصة **مالك المستأجر** بوصفه مالكاً لكل المحطات التي تقع ضمن مساحة المستأجر نفسها. أما أدوار المحطة، وهي المالك المحلي والمدير والمحاسب والمحصل والفني والمشاهد، فتعتمد على سجل `staffProfiles` النشط للمحطة المحددة. لا تمنح عضوية المستأجر من نوع `member` وحدها أي وصول لمحطة لا يملك المستخدم تعييناً نشطاً عليها.

تتحكم الدالة `resolveRole` في هذا القرار، بينما تعيد `sites.list` للعضو محطات تعييناته النشطة فقط. لا يجعل تعيين مستخدم بوصفه مالكاً لمحطة واحدة عضواً مالكاً في مساحة المستأجر؛ تبقى عضويته `member` ما لم يكن مالك المستأجر مسبقاً.

## حدود اختبارات التكامل

يتحقق `server/tenant-isolation.integration.test.ts` من الحالات الآتية باستخدام مستأجرين ومحطتين في المستأجر الأول:

| الحالة | النتيجة المتوقعة |
|---|---|
| مالك مستأجر يصل إلى محطتيه | مسموح |
| مدير محطة يصل إلى محطته الأخرى غير المعيّن عليها | مرفوض |
| عضو مستأجر غير مكلّف بمحطة | لا تظهر له المحطة ولا يقرأ بياناتها |
| مالك محطة مكلّف عبر الفريق فقط | يعمل مالكاً لمحطته ولا يرى المحطة الأخرى |
| مستخدم مستأجر آخر يعيد محاولة إشعار | مرفوض |
| محصل أو فني أو مشاهد ينفذ إجراءً خارج قدرته | مرفوض |
| عملية قراءة ميدانية تعاد بنفس المعرّف | تعاد النتيجة من دون سجل قراءة مكرر |

## حدود اختبارات الواجهة

يتحقق `client/src/pages/role-guards.ui.test.tsx` من حواجز الواجهة للأدوار الستة عبر الفوترة ودليل الشبكة وإعدادات المراسلة وإدارة الفريق والعمليات والقراءات. ويغطي على وجه الخصوص عرض قدرات المحاسب والمحصل والفني والمالك، وإخفاء أدوات الفوترة والشبكة والقراءات والتحصيل والتدقيق عن الأدوار غير المخولة.

## أوامر التحقق المحلية

```bash
pnpm check
pnpm test
RUN_TENANT_ISOLATION_TESTS=1 pnpm vitest run server/tenant-isolation.integration.test.ts
pnpm build
```

تتحقق هذه الأوامر من الأنواع، واختبارات الواجهة، واختبارات الخادم العادية، وعزل قاعدة البيانات الفعلي، والبناء الإنتاجي. لا تغطي عمليات النشر أو إرسال مزود خارجي؛ إذ تظل هذه التفعيلات مؤجلة بطلب المستخدم.
