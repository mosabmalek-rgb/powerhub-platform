# ملاحظات ربط WhatsApp وSMS

## WhatsApp Cloud API — Meta

المصدر الرسمي: https://developers.facebook.com/documentation/business-messaging/whatsapp/get-started

توضح وثائق Meta الرسمية أن WhatsApp Cloud API يتطلب تطبيق Meta، حساب WhatsApp Business، رقم هاتف مفعلاً، Phone Number ID، وAccess Token. كما يتطلب استقبال حالات التسليم والقراءة إعداد Webhook. إرسال الرسائل خارج نافذة خدمة العميل ذات 24 ساعة يعتمد على قوالب معتمدة، ويجب أن يكون المستلم قد وافق على تلقي الرسائل.

المصدر الرسمي للرسائل: https://developers.facebook.com/documentation/business-messaging/whatsapp/messages/send-messages

الرسائل الحرة متاحة داخل نافذة خدمة العميل، أما الرسائل خارجها فتستخدم قوالب Utility أو Authentication أو Marketing حسب التصنيف. لذلك ستبقى واجهة WhatsApp مخفية افتراضياً بناءً على قرار المستخدم، ويُعاد إظهارها من مفتاح الأدمن عند الجاهزية.

## SMS — شركة جوال

نتيجة البحث: https://www.jawwal.ps/en/individuals/9662/9668/9735/9736

تقدم شركة جوال خدمة Bulk SMS للرسائل الجماعية والإشعارات، لكن نقطة API الرسمية، صيغة المصادقة، وحقول الإرسال لم تكن منشورة بوضوح في نتائج التحقق. يجب عدم اختراع endpoint أو صيغة طلب؛ ستبقى واجهة Jawwal جاهزة، ويُفعّل الإرسال بعد استلام وثيقة API أو بيانات العقد الرسمية من جوال.

## قرار التنفيذ

يُخزّن إعداد كل مزود على مستوى صاحب المولد بصورة مشفرة. مفتاح الأدمن يتحكم في ظهور WhatsApp والقنوات التابعة له. SMS سيُعرض باسم شركة جوال ويستخدم قالب الفاتورة وسجل الإرسال وإعادة المحاولة، لكن لن يُرسل أي طلب خارجي قبل إدخال بيانات API الرسمية والتحقق من نقطة الاتصال.
